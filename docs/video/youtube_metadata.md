## Video Description

ProofChain is an evidence-first multi-agent system built for enterprise delivery, IT contracts, and cloud modernization. It transforms complex contracts, statements of work (SOWs), RFPs, and architecture specifications into a living, verifiable Commitment Graph.

Built for the **AWS Agents for Humans Hackathon** (Track: **Professional Agents**).

### Key Capabilities Demonstrated:
- **Autonomous Multi-Agent Extraction**: Strands Agents running on Amazon Bedrock extract commitments, requirements, and evidence with cryptographic SHA-256 hash provenance and exact character offsets.
- **Bipartite Commitment-Evidence Graph**: Visualizes contractual obligations mapped directly to technical and operational evidence (Multi-AZ architecture, uptime audits, SOC 2 reports).
- **Invalidation Cascade**: Downstream risk propagation when evidence expires or architecture changes, alerting delivery leadership before SLA breaches occur.
- **Cross-Document Conflict Detection**: Catches hidden semantic and numerical contradictions across hundreds of pages (e.g., commercial 15-minute RTO promise vs. engineering 4-hour RTO specification).
- **Human-in-the-Loop Autonomous Actions**: Generates concrete mitigations (Aurora Global Database deployment, SOW amendments) with mandatory, cryptographically signed human approval before execution.
